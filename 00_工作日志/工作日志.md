## 四、踩坑备忘（复用经验）

1. **DXF 文件含创建时间戳** → "零偏差"验收要比**实体计数/结构**，不能比 md5。
2. **accoreconsole 每次会话在当前目录丢 `.log` 垃圾** → 交付前必须清理。
3. **`dirname(dirname(__file__))` 是迁移脚本的隐形炸弹** → 标杆脚本从原目录迁到子目录后 BASE 会多跳一级，所有输出/校验路径全错且不报错（静默错）。
4. **含中文名的路径写 AutoCAD SCR 必须纯 ASCII** → 用哈希做工作文件名，成品保留中文名。
5. **同一输出目录不能有两个 build 脚本都写** → 旧版脚本会静默覆盖新版成果，必须移出编排。
