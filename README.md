# CAD 出图工作流手册（从零到完整交付 · 可移植升级版）

> 提炼自「A-1 开放办公区室内设计（毕业设计）」标杆成品（同学版，27+ 张 CAD 图；学生信息已脱敏）的实际生产过程。
> **本版核心升级**：把整条管线做成**跨电脑/跨账号零偏差可复现**——路径、字体、AutoCAD 全部解耦，
> 并随包带字体与源底图。所有规范/数字来自本项目真实运行的脚本与验收记录，非理论模板。

## ★ 30 秒上手（在任意一台电脑）

```bash
cd CAD出图工作流/cad_pipeline
python setup_env.py      # 建隔离环境 + 装依赖 + 拷贝字体 + 探测 AutoCAD + 自检
python run_all.py        # 一键出图（DXF/PDF/PNG；有 AutoCAD/ODA 再补 DWG）
```

> 没有 AutoCAD？照常出 **DXF + PDF + PNG**，DWG 标记"待补"，装了 AutoCAD/ODA 后 `python run_all.py --convert` 补齐。

## `cad_pipeline/` —— 真正"可搬运"的执行包

整套脚本、唯一数据源、随包字体、核心筒源底图都在 `cad_pipeline/` 里，**整包拷走即可在别的电脑重跑**。
唯一解耦点在 `cad_pipeline/config.py`（路径/字体/AutoCAD/ODA/临时目录全部自动解析）。
详见 `07_跨电脑部署与零偏差复现手册.md`。

## 一图速览整条管线

```
数据源 student_master.py（所有数字唯一出处 + assert 强校验）
   ↓
build_9plans（9 平面+PL-00）  build_18drawings（7 立面+6 节点+5 大样）
   ↓  产出 DXF + PNG + PDF（字体从 fonts/ 取）
dwg_convert.py（AutoCAD / ODA / 纯DXF 三后端自动选 → DWG AC1032）
   ↓
verify_9plans / verify_18drawings（C1~C10 程序化复检）
   ↓
verify_dwg_*（魔数 AC1032 + AUDIT 零错误；无 AutoCAD 则跳过）
   ↓
_check_titleblock（图签 17 字段抽查）
   ↓
zip_cad_package.py（CRC 校验打包）
```

**核心思想一句话**：图纸不是"画"出来的，是"生成"出来的——所有数字只写一处（student_master.py），
脚本从数据源渲染，**字体随包、路径解耦**，机器验收代替肉眼；换电脑/换账号只是把 `cad_pipeline/` 拷过去重跑。
