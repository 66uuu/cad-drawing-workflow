## 还原 = 平移 + 缩放，两步缺一不可（作业铁律）
```
附件(46m)核心筒 20500×21100
   │ ① 纯平移 OFF = (−13629.9, −9352.6)        对位到 46m 预留区
   ▼
46m 预留区 (11330,10430)–(31830,31530) = 20500×21100
   │ ② 分段线性映射 MX() / MY()（见数据源 §二）  ★ 不能省
   ▼
37m 目标核心筒 (9714.1,9197.0)–(27290.4,27802.6) = 17576.3×18605.6
```
- 只平移不缩放 → 核心筒大出 14%，图面立刻穿帮。
- 不许等比缩放（AREA_K/SIZE_K），那会让轴网不闭合；必须用数据源的 MX()/MY() 分段线性映射。
- 已实测：附件 372 条核心筒墙线映射后与原成品 PL-01 的 372 条逐条命中 100%。

## 重要说明（复现方式）
本工作流标杆成品里的核心筒几何，是**由 student_cad.py 的「既有核心筒底图」生成函数按上述
映射从数据重建**的（不是每次从 DWG 重新导入），因此**即使没有 AutoCAD、没有这份 DWG，
也能从代码+数据源复现出一致的核心筒**。这份 DWG 作为「权威参考 / 验收比对」随包保留即可。
